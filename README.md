# AgroHub

Aplicativo de gestão agrícola para produtores e agrônomos, com foco em soja e arroz.

## Funcionalidades

- Gestão de talhões e importação de arquivos GPX.
- Registro de safras, operações agrícolas e vistorias.
- Controle de máquinas e serviços de manutenção.
- Mapas interativos e previsão meteorológica.
- Instalação como PWA em navegadores compatíveis.

## Tecnologias

React, TypeScript, TanStack Start, Tailwind CSS, MapLibre e Supabase.

## Desenvolvimento

Node.js 24 e variáveis de ambiente conforme `.env.example`.

```sh
npm install
npm run dev
```

Acesso local: http://127.0.0.1:5173.

## Verificação

```sh
npm run typecheck
npm run lint
npm test
npm run build
```
